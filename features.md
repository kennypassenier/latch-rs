There should be an option to scan an existing project for all .env files and map it to a manifest. This would be a great way to onboard existing projects without requiring users to manually create a manifest from scratch. The tool could recursively search the project directory for .env files, extract their paths, and generate a manifest.json with the appropriate structure. This feature would streamline the setup process and encourage adoption by making it easier for users to get started with Latch-Rs.
