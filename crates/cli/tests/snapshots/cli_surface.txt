═══ latch --help
Encrypted .env secrets, done right (v2)

Usage: latch [OPTIONS] <COMMAND>

Commands:
  login        First-time setup on this machine: PAT + secrets repo, validated live, stored in the keyring or the encrypted credential file (M1)
  init         Link this directory to a project (W1); creates its key on first use
  commit       Encrypt this project's env files into the local clone — offline (W2)
  push         Upload committed secrets (W3); refuses if the remote moved (S4)
  pull         Download and decrypt this project's env files (W4), all-or-nothing
  status       Local vs. committed state per file (W5)
  run          Run a command with secrets injected into its environment — nothing ever touches disk (W6). Works offline on the cached clone (S5)
  cat          Print one env file decrypted to stdout — nothing touches disk (D10). Raw by default: byte-identical to what was committed
  history      List the versions of this project's secrets (S3)
  rollback     Restore this project's secrets to an older version in the clone; push to publish, pull to apply locally (S3)
  verify       Authenticate every ciphertext in the repository without writing anything (S6)
  state        Where does every credential come from, and what is missing? (W8)
  reset        Wipe the local clone + session cache; credentials and config stay (W9)
  diff         What would push change? Key names only; --reveal shows values (W10)
  edit         Edit a secret file in $EDITOR via tmpfs — zero plaintext on disk (W11)
  example      Write keys-only .env.example files (D3 — explicit, never automatic)
  group        W12 file groups: shared content across projects via a pragma line
  key          Key management: show, rotate, backup, restore (K2/K3/K5/K6)
  ui           Open the management TUI (G1)
  project      Manage project↔directory links on this machine (D5)
  path         Where latch is installed and whether it is on PATH (M4)
  update       Self-update from GitHub Releases — checksum-verified, previous binary kept, new binary proven to run before replacing (M5)
  completions  Print shell completions (D7): bash, zsh or fish
  clone        M2 machine clone: move credentials to another machine, E2E-encrypted
  help         Print this message or the help of the given subcommand(s)

Options:
      --non-interactive  Never prompt: anything that would need interactive input becomes a hard error (M7). Auto-detected when there is no terminal
  -h, --help             Print help
  -V, --version          Print version
